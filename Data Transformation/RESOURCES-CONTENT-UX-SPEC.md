# PDF RESOURCES — CONTENT & AUTHORITY SPECIFICATION

## 1. PURPOSE

Resources should make PDF feel capable of:
```text
teach
document
curate
publish
share knowledge
```

## 2. TYPES

Use actual supported types:
```text
Article
Guide
Document
Video
Training material
Judging/adjudication resource
```

## 3. DISCOVERY

Use real:
- search
- category
- type
- date/recency
controls where available.

## 4. RESOURCE CARD

Show:
```text
type
title
short description
date/author where available
CTA
```


## 7. ACADEMY CONNECTION

Only where context is genuinely relevant:
> Want guided training? Explore Academy.

Do not force it on every resource.

## 8. STYLE

Quieter than Home:
- editorial
- readable
- image-led where useful
- low motion
