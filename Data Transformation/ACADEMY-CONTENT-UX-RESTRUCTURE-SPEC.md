# PAK DEBATE FORUM ACADEMY — CONTENT, UX & CREDIBILITY RESTRUCTURE SPECIFICATION

## 1. ROLE

Academy is the structured training arm of PDF, not a separate generic course marketplace.

It should communicate:

```text
learn
→ train
→ compete
→ develop
→ connect
→ pursue higher-level opportunities
```

## 2. AUDIENCE

The Academy is international-facing.

It can serve:
- international students/debaters
- Pakistani students/debaters
- university societies
- aspiring adjudicators
- developing institutions

Do NOT imply it is exclusively for Pakistanis.

## 3. HERO

The podium belongs here.

Desktop:

```text
Academy information     PODIUM
heading                 visual
supporting copy         visual
CTA
```

The podium remains a static premium asset with restrained atmospheric motion.

No fake 3D rotation.

## 4. HERO MESSAGE

Communicate:
- what the Academy develops
- who it serves
- what training can prepare participants for

Avoid generic “Welcome to our Academy” messaging.

## 5. WHY ACADEMY EXISTS

Connect the Academy to PDF's wider mission of access, development, and competitive capacity.

## 6. TRAINING HISTORY

Present the actual trajectory:

```text
2024
FIRST ACADEMY COHORT

2026
COMMUNITY WORKSHOPS

CURRENT
ACADEMY
```

## 8. WHO IT IS FOR

Create clear intent pathways:

```text
Become a stronger speaker
Develop as an adjudicator
Build competitive skills
Get structured training
Develop a society/institution
```

Only connect to real supported flows.

## 9. LEARNING PATHWAY

Visual progression:

```text
FOUNDATIONS
↓
SKILLS
↓
COMPETITIVE APPLICATION
↓
ADVANCED DEVELOPMENT
↓
INTERNATIONAL READINESS
```

These are positioning labels, not invented program names.

## 10. CURRENT PROGRAMS

Use real dynamic program data.

Each card:
- program name
- intended audience/level
- concise value proposition
- duration where available
- status
- CTA

Never invent pricing, curriculum, or guarantees.

## 11. COACHES / EXPERTS

Use approved coach data.
Do not imply teaching responsibilities from judge credentials alone.

## 12. INTERNATIONAL DIMENSION

Make the Academy relevant to an international audience.

Pakistan can be the root of the story without becoming an exclusionary framing.

## 13. SCHOLARSHIPS / ACCESS

Only describe actual Academy scholarships or fee assistance if supported by current program data.

Do not confuse the WUDC scholarship with Academy tuition support.

## 14. STORIES

Use real participant/alumni stories only when approved.

## 15. FAQ

Potential topics:
- who can join
- prior experience
- international participation
- formats taught
- how training works
- how to apply
- scholarships

Answer only with verified policy/data.

## 16. FINAL CTA

Primary:
> Explore Programs

Secondary:
> Contact Academy

## 17. REQUIRED IMAGERY

Priority:
- podium
- training/workshop image
- real debater activity
- coach images
- community/workshop photography
- international/debate environment

## 18. MOBILE

Preferred order:
```text
Academy information
↓
CTA

podium
```
or a wider side composition if genuinely stronger.

Never let the podium consume the mobile experience.
