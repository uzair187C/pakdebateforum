# PDF PROGRAMS — CONTENT & UX SPECIFICATION

## 1. PURPOSE

Programs answers:
```text
Which program is right for me?
What will I work on?
Who is it for?
What is the next step?
```

## 2. INTERNATIONAL AUDIENCE

Do not assume programs are Pakistan-only.

Each program page must state actual eligibility/target audience.

## 3. PROGRAM CARD

Priority:
```text
program name
audience/level
one-line value proposition
status
CTA
```

Optional:
- duration
- format
- coach

only if real data exists.

## 4. DETAIL PAGE

```text
Hero
↓
What this program is
↓
Who it is for
↓
What participants work on
↓
Format / duration
↓
What to expect
↓
Instructor(s)
↓
Application/registration
↓
FAQ
↓
Related programs
```

## 5. VALUE PROPOSITION

Be specific where evidence supports it:
- speaker development
- argumentation
- adjudication
- competitive preparation
- public speaking
- critical thinking

## 6. OUTCOMES

Do not guarantee:
- tournament wins
- team selection
- scholarships
- career outcomes

## 7. CTA STATE

Use:
```text
Apply
Register
View Details
Join Waitlist
Closed
```
according to actual status.

## 8. IMAGERY

Prefer real program/training imagery.

Use a consistent branded fallback when a real image is unavailable.

## 9. MOBILE

Cards should simplify rather than merely shrink.
