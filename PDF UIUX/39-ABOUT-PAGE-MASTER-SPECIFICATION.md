# PAK DEBATE FORUM (PDF) — 39 ABOUT PAGE MASTER SPECIFICATION

Status: Master implementation specification for the public PDF About page.

Purpose:
Define the complete UX/UI, content architecture, visual language, motion system, responsive behavior, component usage, accessibility, and implementation rules for the About page.

This document must be read together with:

- 35 — Global Visual DNA / Design System
- 36 — Global Component Library
- 37 — Site-Wide Page Architecture
- 38 — Homepage / Landing Page Master Specification

The About page must feel unmistakably part of the same PDF website while intentionally moving away from the homepage's dominant cinematic podium composition.

The homepage says:

```text
LOOK
```

The About page should say:

```text
UNDERSTAND
```

The page should communicate who PDF is, why it exists, what it values, how it operates, and who is behind it.

---

# 1. ABOUT PAGE PURPOSE

The About page has six jobs:

1. Explain PDF clearly.
2. Establish organizational credibility.
3. Communicate mission and values.
4. Introduce the people/team where approved.
5. Show the organization's identity and story.
6. Give visitors a clear next action.

The page must not become an autobiography or an unnecessarily long institutional document.

---
